# Mühlberger Digital – Website

Vertriebsseite für **Mühlberger Digital** (Jonas Mühlberger), Vertriebspartner von **Pipeline AI Solutions**.

Statische Seite ohne Build-Schritt: `index.html`, `impressum.html` und `img/`.

## Lokal ansehen

```bash
python -m http.server 8000
```

Dann `http://localhost:8000` öffnen.

## Inhalt

- Startbereich mit freigestelltem Porträt
- Rollen: Mühlberger Digital (Beratung & Vertrieb) und Pipeline AI Solutions (Umsetzung, Vertragspartner)
- Bedarfs-Check mit Empfehlung, die ins Kontaktformular übernommen wird
- Dienstleistungen und Produkte (Pipebot, noteit, SightUp, Pipeflow) mit unverbindlichen Richtpreisen
- Gratis-Checks, Referenzen, Ablauf, Über Jonas, FAQ
- Erstgespräch-Formular (Thema, Wunschtag, Tageszeit) – öffnet eine vorbereitete E-Mail
- Assistent (Chatbot) mit Wissen zu allen Produkten und Rückruf-Aufnahme, läuft komplett im Browser
