Glossar

Digitale Fachbegriffe in einem Satz erklärt – mit Beispielen aus kleinen Betrieben.

Von API bis Workflow: Das Glossar hilft, Angebote zu verstehen und mitzureden.

Kostenloses ErstgesprächKostenloses ErstgesprächGratis-ChecksGratis-Checks
  • A/B-TestEin A/B-Test ist ein Experiment, bei dem zwei Varianten einer Webseite, Anzeige oder E-Mail zufällig verschiedenen Personen gezeigt werden, um zu messen, welche besser wirkt.
  • AbsprungrateDie Absprungrate (Bounce Rate) ist der Anteil der Website-Besuche, bei denen jemand eine Seite aufruft und wieder geht, ohne weiter zu interagieren.
  • APIEine API (Application Programming Interface) ist eine Schnittstelle, über die zwei Programme nach festen Regeln Daten austauschen oder Funktionen voneinander nutzen.
  • AutomatisierungAutomatisierung bedeutet, dass wiederkehrende Arbeitsschritte von Software erledigt werden, statt händisch, etwa das Ablegen von Rechnungen oder das Verschicken von Terminbestätigungen.
  • BacklinkEin Backlink ist ein Link von einer fremden Website auf Ihre eigene, zum Beispiel vom Gemeindeportal oder einem Lieferanten.
  • BarrierefreiheitBarrierefreiheit im Web bedeutet, dass eine Website von allen Menschen genutzt werden kann, auch von Personen mit Seh-, Hör-, motorischen oder kognitiven Einschränkungen.
  • Call-to-ActionEin Call-to-Action (CTA) ist eine Handlungsaufforderung auf einer Website, meist als Schaltfläche oder Link, die Besuchern den nächsten Schritt zeigt, etwa „Jetzt anrufen“ oder „Termin anfragen“.
  • ChatbotEin Chatbot ist ein Programm, das in einem Chatfenster automatisch auf Fragen antwortet, zum Beispiel auf einer Website oder in WhatsApp.
  • CMSEin CMS (Content-Management-System) ist eine Software, mit der Sie die Inhalte Ihrer Website ohne Programmierkenntnisse ändern können.
  • ConversionEine Conversion ist eine gewünschte Handlung eines Website-Besuchers, zum Beispiel eine Anfrage, ein Anruf, eine Reservierung oder ein Kauf.
  • CookieEin Cookie ist eine kleine Textdatei, die eine Website im Browser des Besuchers speichert, um sich etwas zu merken, etwa den Inhalt des Warenkorbs, eine Spracheinstellung oder eine Kennung für Statistik und Werbung.
  • Core Web VitalsCore Web Vitals sind drei von Google definierte Messwerte für die Nutzererfahrung einer Website: Ladegeschwindigkeit des Hauptinhalts (LCP), Reaktion auf Eingaben (INP) und visuelle Stabilität (CLS).
  • CrawlerEin Crawler ist ein Programm, das automatisch Webseiten aufruft, ihre Inhalte liest und Links folgt, um weitere Seiten zu finden.
  • CRMEin CRM (Customer Relationship Management) ist eine Software, in der ein Betrieb alle Informationen zu Kunden und Interessenten an einem Ort sammelt: Kontaktdaten, Gespräche, Angebote, Aufträge und nächste Schritte.
  • DNSDNS (Domain Name System) ist das System, das eine Domain wie tischlerei-gruber.at in die technische Adresse eines Servers übersetzt.
  • DomainEine Domain ist die Internetadresse, unter der Ihre Website und meist auch Ihre E-Mail erreichbar ist, zum Beispiel muster-installateur.at.
  • DSGVODie DSGVO (Datenschutz-Grundverordnung) ist eine EU-Verordnung, die seit Mai 2018 regelt, wie Unternehmen personenbezogene Daten erheben, speichern und nutzen dürfen.
  • EngagementEngagement bezeichnet in sozialen Netzwerken alle Reaktionen auf einen Beitrag, also Likes, Kommentare, geteilte Beiträge, Speicherungen und Klicks.
  • GEOGEO (Generative Engine Optimization) ist die Optimierung von Inhalten, damit KI-Systeme wie ChatGPT, Gemini oder Perplexity einen Betrieb in ihren Antworten nennen und richtig beschreiben.
  • Google-UnternehmensprofilDas Google-Unternehmensprofil ist ein kostenloser Firmeneintrag, der in der Google-Suche und in Google Maps erscheint und Adresse, Öffnungszeiten, Telefonnummer, Fotos und Bewertungen eines Betriebs zeigt.
  • HalluzinationEine Halluzination ist eine Antwort eines KI-Sprachmodells, die überzeugend klingt, aber sachlich falsch oder frei erfunden ist, etwa ein nicht existierendes Gesetz oder eine falsche Telefonnummer.
  • HostingHosting ist die Dienstleistung, bei der ein Anbieter Ihre Website auf einem ständig erreichbaren Server speichert und an Besucher ausliefert.
  • ImpressumEin Impressum ist der Bereich einer Website, in dem ein Betrieb gesetzlich vorgeschriebene Angaben über sich macht, etwa Name, Anschrift, Kontakt und Unternehmensgegenstand.
  • Inbound-MarketingInbound-Marketing ist ein Ansatz, bei dem ein Betrieb Kunden nicht aktiv anspricht, sondern mit hilfreichen Inhalten und guter Sichtbarkeit dafür sorgt, dass sie von selbst kommen und anfragen.
  • IndexierungIndexierung ist der Vorgang, bei dem eine Suchmaschine eine gefundene Webseite auswertet und in ihren Suchindex aufnimmt.
  • Interne VerlinkungInterne Verlinkung bedeutet, dass Seiten einer Website mit Links aufeinander verweisen, etwa von der Startseite zur Leistungsseite oder von einem Ratgeber zum Kontaktformular.
  • KaltakquiseKaltakquise ist die erste Kontaktaufnahme mit möglichen Kunden, die noch keine Beziehung zu Ihrem Betrieb haben und nicht von sich aus angefragt haben, etwa per Anruf, Brief, E-Mail oder persönlichem Besuch.
  • KeywordEin Keyword ist ein Wort oder eine Wortgruppe, die Menschen in eine Suchmaschine eingeben, etwa „Elektriker Krems“ oder „Hochzeitstorte bestellen“.
  • KI-ÜbersichtDie KI-Übersicht ist eine von Google mit künstlicher Intelligenz erstellte Zusammenfassung, die bei vielen Suchanfragen über den klassischen Ergebnissen erscheint und auf einige Quellen verlinkt.
  • LandingpageEine Landingpage ist eine einzelne Webseite, die auf genau ein Angebot und eine gewünschte Handlung ausgerichtet ist, etwa eine Anfrage oder Anmeldung.
  • Large Language ModelEin Large Language Model (LLM) ist ein großes KI-Sprachmodell, das mit sehr vielen Texten trainiert wurde und daraus gelernt hat, Sprache zu verstehen und neue Texte zu erzeugen.
  • LeadEin Lead ist ein Kontakt, der Interesse an Ihrem Angebot gezeigt hat oder gut zu Ihrem Angebot passt und dessen Kontaktdaten Sie haben, etwa nach einer Anfrage, einem Messegespräch oder einem Download.
  • LeadgenerierungLeadgenerierung ist die gezielte Gewinnung von Interessenten, die zu Ihrem Angebot passen und deren Kontaktdaten Sie erhalten, damit daraus Gespräche und Aufträge werden.
  • llms.txtDie llms.txt ist eine vorgeschlagene Textdatei im Hauptverzeichnis einer Website, die KI-Sprachmodellen in einfacher Form zusammenfasst, worum es auf der Seite geht und wo die wichtigsten Inhalte liegen.
  • Local SEOLocal SEO ist der Teil der Suchmaschinenoptimierung, der dafür sorgt, dass ein Betrieb bei ortsbezogenen Suchen wie „Tischler in der Nähe“ oder „Pizzeria Horn“ gefunden wird.
  • Meta-DescriptionDie Meta-Description ist eine kurze Beschreibung einer Webseite, die im Quelltext hinterlegt wird und oft als Text unter dem Titel in den Google-Ergebnissen erscheint.
  • NAP-DatenNAP-Daten sind die Grunddaten eines Betriebs: Name (Name), Adresse (Address) und Telefonnummer (Phone).
  • Native AppEine native App ist eine Anwendung, die speziell für ein Betriebssystem wie iOS oder Android entwickelt und über den jeweiligen App-Store installiert wird.
  • OnlineshopEin Onlineshop ist eine Website oder ein Bereich einer Website, auf dem Kunden Produkte oder Leistungen auswählen, bestellen und bezahlen können.
  • Payment-ProviderEin Payment-Provider ist ein Zahlungsdienstleister, der Onlinezahlungen für Ihren Shop oder Ihre Website abwickelt, etwa per Kreditkarte, Debitkarte, PayPal, Apple Pay oder Online-Überweisung.
  • PromptEin Prompt ist die Eingabe, mit der Sie einem KI-Sprachmodell sagen, was es tun soll, etwa eine Frage, eine Aufgabe oder ein Text mit Anweisungen.
  • PWAEine PWA (Progressive Web App) ist eine Web-App, die sich wie eine installierte App verhält: Sie lässt sich auf den Startbildschirm legen, öffnet sich ohne Browserleiste und kann Inhalte für die Offline-Nutzung zwischenspeichern.
  • RAGRAG (Retrieval Augmented Generation) ist ein Verfahren, bei dem eine KI vor dem Antworten passende Stellen aus einer festgelegten Wissensquelle sucht und ihre Antwort darauf stützt.
  • RedaktionsplanEin Redaktionsplan ist eine Übersicht, in der Sie festlegen, welche Inhalte wann auf welchem Kanal veröffentlicht werden, etwa Beiträge auf Instagram, LinkedIn oder der eigenen Website.
  • Responsive DesignResponsive Design ist eine Bauweise für Websites, bei der sich Layout, Schrift und Bilder automatisch an die Bildschirmgröße anpassen.
  • Rich SnippetEin Rich Snippet ist ein Suchergebnis, das neben Titel und Beschreibung zusätzliche Informationen zeigt, etwa Bewertungssterne, Preise, Verfügbarkeit oder Veranstaltungstermine.
  • robots.txtDie robots.txt ist eine einfache Textdatei im Hauptverzeichnis einer Website, die Crawlern von Suchmaschinen und KI-Diensten mitteilt, welche Bereiche sie abrufen dürfen und welche nicht.
  • SaaSSaaS (Software as a Service) ist ein Modell, bei dem Sie Software nicht kaufen und installieren, sondern über das Internet nutzen und meist monatlich bezahlen.
  • Sales FunnelEin Sales Funnel (Verkaufstrichter) ist ein Modell, das die Stufen beschreibt, die ein Kunde vom ersten Kontakt mit Ihrem Betrieb bis zum Auftrag durchläuft.
  • Schema-MarkupSchema-Markup ist ein standardisierter Code, mit dem Sie Inhalte Ihrer Website für Maschinen eindeutig beschreiben, etwa „das ist eine Adresse“ oder „das sind die Öffnungszeiten“.
  • SEOSEO (Suchmaschinenoptimierung) ist die Arbeit daran, dass eine Website in den unbezahlten Ergebnissen von Suchmaschinen wie Google besser gefunden wird.
  • SERPSERP (Search Engine Results Page) ist die Ergebnisseite, die eine Suchmaschine nach einer Suchanfrage anzeigt.
  • SSL-ZertifikatEin SSL-Zertifikat ist ein digitaler Nachweis, mit dem Ihre Website eine verschlüsselte Verbindung zum Browser aufbaut.
  • Title-TagDer Title-Tag ist der Titel einer Webseite, der im Quelltext steht, im Browser-Tab angezeigt wird und meist als blaue Überschrift in den Google-Ergebnissen erscheint.
  • TokenEin Token ist ein kleines Textstück, meist ein Wort oder Wortteil, in das ein KI-Sprachmodell Eingaben und Antworten zerlegt.
  • VertriebspartnerEin Vertriebspartner ist eine selbständige Person oder Firma, die Produkte oder Dienstleistungen eines anderen Unternehmens an Kunden vermittelt und dafür meist eine Provision erhält.
  • Web-AppEine Web-App ist eine Anwendung, die im Browser läuft und ohne Installation aus einem App-Store genutzt wird, zum Beispiel ein Buchungssystem, ein Kundenportal oder ein Bestellformular mit Login.
  • WebhookEin Webhook ist eine automatische Benachrichtigung, die ein Programm an eine festgelegte Internetadresse schickt, sobald ein bestimmtes Ereignis eintritt, etwa eine neue Bestellung oder ein ausgefülltes Formular.
  • WorkflowEin Workflow ist ein festgelegter Arbeitsablauf aus aufeinanderfolgenden Schritten, der durch ein Ereignis ausgelöst wird und zu einem bestimmten Ergebnis führt.
  • XML-SitemapEine XML-Sitemap ist eine Datei, die alle wichtigen Seiten einer Website in maschinenlesbarer Form auflistet, damit Suchmaschinen sie leichter finden.
