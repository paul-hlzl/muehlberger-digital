Prompt – die Anweisung an die KI

Ein Prompt ist die Eingabe, mit der Sie einem KI-Sprachmodell sagen, was es tun soll, etwa eine Frage, eine Aufgabe oder ein Text mit Anweisungen. Je klarer der Prompt, desto brauchbarer ist in der Regel das Ergebnis.

Auf einen Blick
  • Gute Prompts nennen Rolle, Aufgabe, Kontext und gewünschtes Format
  • Beispiele im Prompt verbessern Stil und Treffsicherheit
  • Vertrauliche Daten gehören nicht ungeprüft in einen Prompt

Schwacher und guter Prompt im Vergleich

Ein Gärtner tippt „Schreib einen Text über Heckenschnitt“ und bekommt einen allgemeinen Aufsatz. Besser ist ein Prompt mit Kontext:

  • Rolle: „Du schreibst für einen Gartenbaubetrieb im Mostviertel.“
  • Aufgabe: „Schreib einen kurzen Beitrag für die Website, wann man Hecken schneiden sollte.“
  • Vorgaben: „Sie-Form, österreichisches Deutsch, höchstens 150 Wörter, am Ende Hinweis auf unseren Schnittservice.“

Das Ergebnis passt deutlich besser und muss kaum nachbearbeitet werden. Fakten wie Schnittzeiten prüft der Gärtner trotzdem selbst.

Warum gutes Prompten für KMU zählt

Die Qualität der KI-Ergebnisse hängt stark von der Eingabe ab. Wer ein paar Grundregeln kennt, spart sich viele Korrekturschleifen. Bewährte Prompts lassen sich als Vorlage im Team teilen, etwa für Angebote oder Antworten auf Bewertungen.

Praxisbeispiele zeigen die Ratgeber ChatGPT im Betrieb und KI-Texte im eigenen Stil. Wie ein Sprachmodell den Prompt verarbeitet, erklärt der Eintrag Large Language Model; eine Einführung fürs Team bietet KI-Schulung.

Häufige Fragen

Muss ich Prompts auf Englisch schreiben?

Nein. Aktuelle Sprachmodelle verstehen Deutsch sehr gut und antworten auch auf Deutsch. Wenn Sie österreichische Begriffe wie „Jänner“ oder „Erdäpfel“ bevorzugen, sagen Sie das im Prompt ausdrücklich. Hilfreich ist auch ein kurzer Beispieltext in Ihrem gewohnten Stil, an dem sich das Modell orientieren kann. Englisch bringt für normale Büroaufgaben keinen spürbaren Vorteil.

Was ist ein Systemprompt?

Ein Systemprompt ist eine Grundanweisung, die im Hintergrund vor jedem Gespräch an das Modell geht, etwa „Du bist der Assistent einer Zahnarztpraxis, antworte nur zu Praxisthemen“. Nutzer sehen ihn meist nicht. Chatbots auf Websites arbeiten mit solchen Systemprompts, damit sie im richtigen Ton bleiben und nicht über beliebige Themen sprechen.
