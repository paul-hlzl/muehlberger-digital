Glossar · Technik

Webhook

Ein Webhook ist eine automatische Benachrichtigung, die ein Programm an eine festgelegte Internetadresse schickt, sobald ein bestimmtes Ereignis eintritt, etwa eine neue Bestellung oder ein ausgefülltes Formular. Das empfangende Programm kann dann sofort reagieren.

Ein Webhook im Alltag

Ein Hofladen verkauft Kistl mit Gemüse über einen kleinen Onlineshop. Bei jeder Bestellung schickt der Shop einen Webhook an ein Automatisierungswerkzeug. Dieses trägt die Bestellung in die Packliste für Freitag ein, schickt dem Kunden eine Abholzeit und informiert die Bäuerin per Nachricht.

Der Unterschied zur API: Bei einer API fragt ein Programm aktiv nach Daten. Beim Webhook meldet sich das andere Programm von selbst, sobald etwas passiert. Das ist schneller und spart unnötige Abfragen.

Warum Webhooks für KMU nützlich sind

Webhooks sind der Startschuss vieler Workflows. Ohne sie müsste jemand regelmäßig nachsehen, ob es Neuigkeiten gibt. Für kleine Betriebe heißt das: schnellere Reaktion auf Kunden und weniger händische Kontrolle. Viele Shop-, Formular- und Zahlungsdienste bieten Webhooks standardmäßig an.

Häufige Fragen

Muss ich Webhooks selbst einrichten?

Bei vielen Werkzeugen ist das mit wenigen Klicks erledigt: Sie kopieren eine Empfangsadresse aus dem Automatisierungswerkzeug und tragen sie im Shop oder Formulardienst ein. Für individuelle Abläufe, sensible Daten oder Verbindungen zu älterer Software braucht es meist technische Unterstützung. Wichtig ist in jedem Fall ein Test mit Beispieldaten, bevor echte Kunden betroffen sind.

Sind Webhooks sicher?

Sie sind sicher, wenn die Empfangsadresse geheim bleibt, die Verbindung über HTTPS läuft und der Empfänger prüft, ob die Nachricht wirklich vom erwarteten Absender stammt. Viele Dienste signieren ihre Webhooks dafür. Geben Sie Webhook-Adressen nicht weiter und deaktivieren Sie ungenutzte Verbindungen, damit niemand gefälschte Ereignisse einschleusen kann.
