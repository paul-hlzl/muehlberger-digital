DNS – Domain Name System

DNS (Domain Name System) ist das System, das eine Domain wie tischlerei-gruber.at in die technische Adresse eines Servers übersetzt. Ohne DNS wüsste kein Browser und kein Mailprogramm, wohin es sich verbinden soll.

Auf einen Blick
  • Übersetzt Namen in IP-Adressen, ähnlich einem Telefonbuch
  • Wichtige Einträge: A/AAAA (Website), MX (E-Mail), TXT (Nachweise)
  • Änderungen brauchen oft einige Stunden, bis sie überall gelten

Was DNS-Einträge im Betrieb steuern

Ein Elektrotechniker zieht mit seiner Website zu einem neuen Hosting-Anbieter um, die E-Mails sollen aber beim bisherigen Anbieter bleiben. Dafür wird im DNS seiner Domain nur der A-Eintrag auf den neuen Server geändert, der MX-Eintrag für die Post bleibt gleich. Kunden merken vom Umzug nichts.

Über TXT-Einträge wird außerdem nachgewiesen, wer E-Mails im Namen der Domain verschicken darf (SPF, DKIM, DMARC). Fehlen sie, landen Angebote leichter im Spam-Ordner des Kunden.

Warum DNS für KMU relevant ist

Die meisten Betriebe sehen ihr DNS nie, bis etwas nicht funktioniert. Ein falsch gesetzter Eintrag kann Website oder E-Mail für Stunden lahmlegen. Notieren Sie deshalb, bei welchem Anbieter Ihr DNS verwaltet wird und wer Zugriff hat.

Bei einem Relaunch oder Anbieterwechsel gehört die DNS-Umstellung auf jede Checkliste, siehe Relaunch-Checkliste. Wer eigene Adressen nutzt, findet im Ratgeber E-Mail mit eigener Domain die passenden Schritte.

Häufige Fragen

Warum dauert eine DNS-Änderung so lange?

DNS-Daten werden weltweit zwischengespeichert, damit nicht bei jedem Aufruf neu nachgefragt werden muss. Wie lange, bestimmt ein Wert namens TTL (Time to Live). Bis alle Zwischenspeicher den neuen Eintrag übernommen haben, sehen manche Besucher noch die alte Version. Meist ist das nach einigen Stunden erledigt, in seltenen Fällen kann es bis zu einem Tag dauern.

Muss ich mich als Betrieb selbst um das DNS kümmern?

Nein, in der Regel übernimmt das Ihr Webdienstleister oder Hosting-Anbieter. Sie sollten aber wissen, wo Ihr DNS verwaltet wird, und die Zugangsdaten sicher aufbewahren. So können Sie bei einem Anbieterwechsel oder einem Problem schnell reagieren, ohne auf eine einzelne Person angewiesen zu sein.
