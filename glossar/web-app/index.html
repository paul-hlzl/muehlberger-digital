Web-App – Anwendung im Browser

Eine Web-App ist eine Anwendung, die im Browser läuft und ohne Installation aus einem App-Store genutzt wird, zum Beispiel ein Buchungssystem, ein Kundenportal oder ein Bestellformular mit Login. Sie funktioniert auf Computer, Tablet und Smartphone gleichermaßen.

Ein Beispiel aus dem Betrieb

Ein Getränkehändler beliefert Gasthäuser und Vereine. Bisher kommen Bestellungen per Telefon, SMS und Zettel. Mit einer Web-App melden sich die Wirte im Browser an, sehen ihre letzten Bestellungen, ändern Mengen und schicken die Bestellung ab. Der Fahrer ruft am Tablet die Tagesroute mit allen Lieferungen auf.

Im Unterschied zu einer normalen Website gibt es Logins, gespeicherte Daten und Funktionen. Im Unterschied zur nativen App muss niemand etwas installieren, und eine Freigabe durch einen App-Store entfällt.

Warum Web-Apps für KMU interessant sind

Für viele interne Werkzeuge und Kundenportale ist eine Web-App die günstigere und schneller umsetzbare Lösung als eine App für iPhone und Android. Mit Funktionen einer PWA lässt sie sich sogar wie eine App auf den Startbildschirm legen. Grenzen gibt es bei manchen Gerätefunktionen.

Häufige Fragen

Funktioniert eine Web-App auch ohne Internet?

Klassische Web-Apps brauchen eine Internetverbindung. Mit den Techniken einer Progressive Web App können aber Teile der Anwendung zwischengespeichert werden, sodass etwa zuletzt geladene Daten auch offline sichtbar sind und Eingaben später übertragen werden. Wie gut das funktioniert, hängt von der Umsetzung ab. Wenn Offline-Nutzung wichtig ist, sollte das von Anfang an eingeplant werden.

Ist eine Web-App sicher genug für Kundendaten?

Ja, wenn sie sorgfältig gebaut und betrieben wird: verschlüsselte Verbindung über HTTPS, sichere Anmeldung, klare Benutzerrechte, regelmäßige Updates und ein Server mit Standort in der EU. Wichtig ist auch, wer im Betrieb welche Daten sehen darf. Lassen Sie sich vom Dienstleister erklären, wie Daten gespeichert und gesichert werden.
