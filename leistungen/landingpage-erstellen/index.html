Landingpage erstellen lassen: eine Seite mit einem klaren Ziel

Eine Landingpage ist eine einzelne Seite, die genau ein Ziel verfolgt: eine Anfrage, eine Anmeldung, eine Bewerbung oder eine Buchung. Sie eignet sich für ein bestimmtes Angebot, eine Aktion oder eine Stellenausschreibung, ersetzt aber in der Regel keine vollständige Website. Wir klären mit Ihnen, ob eine Landingpage Ihr Ziel besser erreicht als eine weitere Unterseite, und setzen sie dann um.

Was eine Landingpage von einer normalen Website unterscheidet

Eine Website zeigt Ihren ganzen Betrieb: alle Leistungen, Team, Kontakt, vielleicht Geschichte und Galerie. Besucher können sich frei umsehen. Eine Landingpage macht das Gegenteil: Sie konzentriert sich auf ein einziges Thema und führt Schritt für Schritt zu einer Handlung.

  • Kein großes Menü, das ablenkt. Alles, was nicht zum Ziel beiträgt, bleibt weg.
  • Eine zentrale Aussage gleich oben: Was ist das Angebot, für wen, was bringt es?
  • Antworten auf die typischen Einwände: Preis, Ablauf, Dauer, Vertrauen.
  • Ein klarer Handlungsaufruf, etwa „Jetzt Termin anfragen“, der mehrmals auftaucht.

Die ausführliche Entscheidungshilfe finden Sie im Ratgeber Landingpage oder Website?.

Wofür sich eine Landingpage lohnt – und wofür nicht

Eine Landingpage spielt ihre Stärke aus, wenn Sie Menschen gezielt auf eine Seite schicken, zum Beispiel über eine Anzeige, einen Flyer mit QR-Code, einen Newsletter oder einen Social-Media-Beitrag.

Typische Einsätze

  • Ein Tischler bietet neu Komplettküchen an und bewirbt sie in der Regionalzeitung. Die Landingpage zeigt nur dieses Angebot und sammelt Beratungsanfragen.
  • Ein Baumeister sucht Lehrlinge. Statt einer versteckten Unterseite gibt es eine eigene Seite, die jungen Leuten in ihrer Sprache erklärt, was sie erwartet, mit einfacher Bewerbungsmöglichkeit.
  • Ein Verein organisiert ein Fest und möchte Anmeldungen für einen Wettbewerb an einer Stelle sammeln.
  • Eine Steuerberatung bietet eine Infoveranstaltung an und braucht eine Seite für die Anmeldung.

Wann eine Landingpage nicht die richtige Wahl ist

Wenn Sie noch gar keine Website haben, ist eine einzelne Aktionsseite meist zu wenig. Interessenten wollen sich auch über den Betrieb dahinter informieren. Dann fahren Sie mit der Starter-Website besser, in der eine zielgerichtete Seite Platz hat. Und wenn niemand gezielt auf die Seite geschickt wird, bleibt auch die beste Landingpage unbesucht. Sie braucht immer einen Weg, über den Menschen hinkommen.

So bauen wir Ihre Landingpage auf

Bevor gestaltet wird, legen wir gemeinsam drei Dinge fest: das eine Ziel, die Zielgruppe und den Weg, über den Besucher kommen. Daraus ergibt sich der Aufbau, der sich in der Praxis bewährt:

  1. Überschrift mit Nutzen: Was bekommt der Besucher, in einem Satz.
  2. Kurze Erklärung des Angebots, mit einem aussagekräftigen Foto aus Ihrem Betrieb.
  3. Vorteile und Ablauf in wenigen, klaren Punkten.
  4. Vertrauen: wer hinter dem Angebot steht, Kontaktmöglichkeit, gegebenenfalls Zertifikate oder Mitgliedschaften, die Sie tatsächlich haben.
  5. Häufige Fragen, die sonst am Telefon gestellt würden.
  6. Handlungsaufruf mit einem einfachen Formular: so wenige Felder wie möglich.

Wie man den entscheidenden Knopf formuliert, beschreibt der Ratgeber Call-to-Action. Nach dem Start lohnt ein Blick, wie viele Besucher tatsächlich anfragen. Dafür eignet sich eine Besucherstatistik, die ohne Cookie-Banner auskommt.

Was eine Landingpage kostet

Der Preis für eine Landingpage hängt davon ab, ob sie an eine bestehende Website angebunden wird, ob ein Formular mit besonderen Feldern oder eine Buchungsfunktion nötig ist und wer die Texte schreibt. Deshalb nennen wir den Preis nach dem kostenlosen Erstgespräch in einem schriftlichen Angebot.

Zum Vergleich: Die Starter-Website mit bis zu fünf Seiten, Kontaktformular, Impressum, Datenschutz und Hosting kostet ab 2.500 € einmalig. Alle Preise sind unverbindliche Richtpreise ohne Umsatzsteuer. Wer ohnehin eine neue Website braucht, sollte die Landingpage gleich mitplanen, statt zwei getrennte Projekte zu beauftragen.

Was eine Landingpage ergänzt

Eine Landingpage wird erst wirksam, wenn Besucher kommen und Fragen schnell beantwortet werden. Diese Bausteine passen dazu, wenn es die Situation hergibt:

  • Social-Media-Beiträge: Mit Pipeflow entstehen aus Ihrer Website jede Woche fertige Beiträge mit Bild für Instagram und LinkedIn, die Sie nur freigeben. Pipeflow ist in der Pilotphase kostenlos.
  • Chatbot: Bei erklärungsbedürftigen Angeboten beantwortet Pipebot Fragen rund um die Uhr mit Ihren eigenen Inhalten, für 19 € pro Monat, die ersten 30 Tage gratis.
  • Stellenausschreibungen: Für Recruiting-Seiten kann zusätzlich die kostenlose Bewerbungsplattform zusage.at sinnvoll sein.

Typische Fehler bei Landingpages

  • Mehrere Ziele auf einer Seite: Wer gleichzeitig zum Anrufen, zum Newsletter und zum Shop einlädt, bekommt oft gar nichts.
  • Die Seite passt nicht zur Anzeige: Verspricht die Anzeige einen Aktionspreis, muss genau dieser oben auf der Landingpage stehen.
  • Zu lange Formulare: Jede zusätzliche Pflichtangabe ist ein Grund, abzubrechen. Fragen Sie nur, was Sie für den ersten Kontakt wirklich brauchen.
  • Nur am Computer getestet: Viele Besucher kommen über das Handy. Dort muss der Knopf ohne Suchen erreichbar sein.
  • Aktion vorbei, Seite noch online: Abgelaufene Angebote wirken unprofessionell. Planen Sie ein Ende oder eine Aktualisierung ein.

Häufige Fragen

Was ist eine Landingpage?

Eine Landingpage ist eine einzelne Webseite, die auf ein bestimmtes Angebot ausgerichtet ist und Besucher zu genau einer Handlung führt, zum Beispiel einer Anfrage, Anmeldung oder Bewerbung. Im Unterschied zu einer normalen Website verzichtet sie auf ein großes Menü und Ablenkungen. Besucher kommen meist gezielt über eine Anzeige, einen QR-Code, einen Newsletter oder einen Social-Media-Beitrag.

Brauche ich eine Landingpage, wenn ich schon eine Website habe?

Nicht immer. Wenn Sie ein Angebot gezielt bewerben, etwa über Anzeigen oder Flyer, wirkt eine eigene Landingpage meist besser als ein Verweis auf die Startseite, weil Besucher sofort finden, was ihnen versprochen wurde. Für Leistungen, die Sie dauerhaft anbieten und nicht gesondert bewerben, reicht oft eine gut gemachte Unterseite Ihrer bestehenden Website.

Was kostet es, eine Landingpage erstellen zu lassen?

Den Preis nennen wir nach dem kostenlosen Erstgespräch in einem schriftlichen Angebot, weil er von Anbindung, Formular, Texten und Zusatzfunktionen abhängt. Zur Einordnung: Die Starter-Website mit bis zu fünf Seiten kostet ab 2.500 € einmalig, als unverbindlicher Richtpreis ohne Umsatzsteuer. Wer ohnehin eine neue Website braucht, plant die Landingpage am besten gleich mit.

Kann eine Landingpage bei Google gefunden werden?

Ja, wenn sie ein Thema behandelt, nach dem Menschen suchen, und ausreichend Inhalt bietet. Viele Landingpages sind aber für Besucher aus Werbung oder Aktionen gedacht und müssen gar nicht über die Google-Suche gefunden werden. Ob Ihre Seite auf Suchmaschinen oder auf eine Kampagne ausgerichtet sein soll, klären wir vor der Umsetzung, weil sich danach Aufbau und Textlänge richten.

Wie viele Felder sollte das Formular auf einer Landingpage haben?

So wenige wie möglich. Für eine erste Anfrage reichen oft Name, Telefonnummer oder E-Mail und ein freies Nachrichtenfeld. Jede zusätzliche Pflichtangabe senkt die Bereitschaft, das Formular abzuschicken. Details wie genaue Maße, Termine oder Budget können Sie im ersten Gespräch klären. Wichtig ist auch ein kurzer Hinweis zum Datenschutz beim Formular.
