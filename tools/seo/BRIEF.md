# Text-Briefing: SEO-/GEO-Seiten für muehlberger-digital.at

Du schreibst Inhalte für Unterseiten der Website von **Mühlberger Digital**. Jede Seite muss für sich genommen nützlich sein: Ein Inhaber eines kleinen Betriebs liest sie und weiß danach mehr als vorher. Google wertet massenhaft erzeugte, austauschbare Seiten ab („Scaled Content Abuse“, „Doorway Pages“). Deshalb gilt: **Jede Seite hat einen eigenen Blickwinkel, eigene Beispiele und eigene Antworten.** Keine Absätze, die mit getauschtem Ortsnamen oder Branchenwort auf einer anderen Seite stehen könnten.

## Verboten

- **Erfundene Fakten**: keine Zahlen, Statistiken, Studien, Einwohnerzahlen, Firmennamen, Kundenreferenzen, Zitate, Bewertungen, Projektbeispiele mit Namen, Förderhöhen, Fristen oder Paragraphen, die du nicht sicher weißt. Lieber qualitativ formulieren („viele Betriebe“, „in der Regel“). Beispiele als **typische Situationen** schreiben („Ein Installateur mit zwei Mitarbeitern…“), nie als echte Kunden.
- **Garantien**: kein „Platz 1 garantiert“, kein „sofort mehr Kunden“. Erlaubt: „Wir sagen zu, was wir tun – Ergebnisse sehen Sie im Bericht.“
- **Rechtsberatung**: Rechtsthemen nur als allgemeine Orientierung, mit dem Hinweis, im Einzelfall WKO, Anwalt oder Datenschutzbehörde zu fragen. Keine konkreten Paragraphen, außer du bist dir sicher.
- **Floskeln**: „In der heutigen digitalen Welt“, „Zeit ist Geld“, „Gamechanger“, „revolutionär“, „maßgeschneidert“ als Füllwort, „Tauchen wir ein“, Ausrufezeichen-Ketten, Emojis.
- **Keyword-Stuffing**: Suchbegriff natürlich verwenden, im H1 und in ein, zwei Zwischenüberschriften, sonst Synonyme.
- **Konkurrenz schlechtmachen**, Provisionen von Mühlberger Digital nennen, interne Vereinbarungen.
- Für **regionale Seiten**: keine erfundenen Ortsdetails. Erlaubt sind allgemein bekannte, sichere Dinge (Bundesland, Viertel, Bezirkshauptstadt, Landschaft, typische Branchenstruktur wie „viele Handwerks- und Familienbetriebe“, Tourismus in bekannten Regionen wie Wachau oder Kamptal). Wenn du dir bei einem Detail unsicher bist: weglassen.

- **Österreichisches Deutsch**, Anrede **„Sie“**, klar, freundlich, konkret, ohne Fachchinesisch (Fachbegriffe kurz erklären).
- Kurze Absätze (2–4 Sätze), aussagekräftige Zwischenüberschriften, Listen wo sinnvoll.

## Ausgabeformat

Schreibe **pro Seite eine Datei** `content/<typ>/<dateiname>.json`. `<dateiname>` = `slug`, bei Kombi-Seiten `/` durch `__` ersetzen (z. B. `content/kombi/seo__zwettl.json`). UTF-8, gültiges JSON:

```json
{
  "pfad": "/wissen/was-kostet-eine-website/",
  "title": "Was kostet eine Website in Österreich? Preise & Faktoren",
  "description": "140–158 Zeichen, mit Nutzen und natürlich formuliertem Suchbegriff.",
  "h1": "Was kostet eine Website in Österreich?",
  "kicker": "Ratgeber · Website",
  "lead": "Direkte Antwort in 2–3 Sätzen.",
  "fakten": ["3–5 kurze Stichpunkte für die Box „Auf einen Blick“ (je max. 110 Zeichen)"],
  "abschnitte": [
    { "h2": "Zwischenüberschrift", "html": "<p>…</p><ul><li>…</li></ul>" }
  ],
  "faq": [ { "q": "Frage?", "a": "Vollständige Antwort." } ],
  "verwandt": ["/wissen/website-laufende-kosten/", "/leistungen/website-erstellen/", "/gratis-check/website-entwurf/"],
  "checks": ["website-entwurf"]
}
```

Regeln für die Felder:
- `title`: 35–60 Zeichen, ohne Markennamen (die Marke hängt der Generator an). Kein Titel doppelt.
- `description`: 120–158 Zeichen.
- `html` darf nur diese Tags enthalten: `p, ul, ol, li, strong, em, a, h3, table, thead, tbody, tr, th, td, br`. Links: `<a href="/pfad/">` intern, `<a href="https://…">` extern (nur Whitelist). Keine Klassen, keine Styles, kein `h1`/`h2`.
- `verwandt`: 3–6 interne Pfade aus plan.json, passend zum Thema.
- `checks`: 1–2 Schlüssel aus `website-entwurf, seo-check, ki-sichtbarkeit, chatbot-test, neukunden-finden, social-media-test`, die thematisch passen.
- Kein Markdown in Feldern, nur Text bzw. das erlaubte HTML. Typografische Anführungszeichen „…“ sind erwünscht; im JSON korrekt escapen.

Prüfe am Ende mit `node tools/seo/check.mjs <dein-batch>`, ob deine Dateien gültig sind, und korrigiere gemeldete Fehler.
